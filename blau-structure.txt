BEM NAMING CONVENTION
============================================================

Pattern: .blau-{block}__{element}--{modifier}

Blocks:
  blau-sidebar        blau-mobile-header    blau-burger
  blau-mobile-nav     blau-section          blau-hero
  blau-dot            blau-social           blau-scroll-hint
  blau-work           blau-btn              blau-accordion
  blau-list           blau-skills           blau-contact
  blau-footer         blau-modal            blau-carousel
  blau-fade           blau-card             blau-lang
  blau-toggle         blau-a11y-btn         blau-tag
  blau-a11y-panel     blau-a11y-dropdown    blau-eyebrow
  blau-heading        blau-divider          blau-categories
  blau-layout         blau-skip-link

State classes (is- prefix):
  .is-open            .is-active            .is-visible

Modifiers:
  --primary           --featured            --soon
  --hero              --nav                 --ready
  --clicked           --rage                --compact
  --slim              --project             --mobile
  --prev              --next                --active


============================================================
THEME SYSTEM
============================================================

Four theme states (both toggles work independently):

  Dark OFF + HC OFF  →  light (default, no data-theme attribute)
  Dark ON  + HC OFF  →  [data-theme="dark"]
  Dark OFF + HC ON   →  [data-theme="high-contrast"]
  Dark ON  + HC ON   →  [data-theme="dark-high-contrast"]

Switching:
  blauTheme.toggleDark()           → toggles dark mode on/off
  blauTheme.toggleHighContrast()   → toggles high-contrast on/off
  blauTheme.toggleAccessible()     → toggles large-text (readable) mode on/off

Persistence: localStorage keys 'blau-dark', 'blau-hc', 'blau-a11y'

UI Controls:
  Desktop: .blau-a11y-panel (collapsible panel at sidebar bottom)
    Trigger: accessibility icon button → expands/collapses body
    Body: 3× .blau-toggle (Dark mode, High contrast, Large text)

  Mobile:  .blau-a11y-dropdown (floating panel from header icon)
    Trigger: #mobA11yBtn (accessibility icon in mobile header)
    Body: 3× .blau-toggle (same controls as sidebar)
